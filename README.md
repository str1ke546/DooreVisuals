# DooreVisuals Landing

Статичный лендинг для GitHub Pages.

## Локально
Открой `index.html` в браузере (или через Live Server).

## GitHub Pages
1. Создай репозиторий (например `doorevisuals-site` или `docs/` в репо мода).
2. Залей содержимое этой папки.
3. Settings → Pages → Deploy from branch → `main` / root.
